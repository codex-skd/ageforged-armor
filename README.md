# Ageforged Armor

Adds 11 unique armor sets with custom 3D models, set bonuses, and configurable stats. Inspired by different cultures and eras of history.

## Requirements

- Minecraft 26.1.2
- NeoForge 26.1.2.78+
- Yet Another Config Lib (YACL) 3.0+

## Armor Sets

- Bamboo Hat, Iron Plate, Holy, Exalted Aurum, Japanese Light
- O-Yoroi (8 skins), Raijin (3 skins), Pharaoh (2 skins)
- Anubis, Centurion (2 skins), Quetzalcoatl

## Features

- Custom 3D models for every armor piece
- Set bonuses with hover tooltips
- Fully configurable stats via YACL
- Loot generation in vanilla structure chests
- Skin variants for select armor sets
