<h2>v0.0.0-beta.22 — First-person arm armor + animation sync</h2>

<h3>Added</h3>
<ul>
<li><strong>First-person arm armor</strong>: Custom armor on the chest slot now renders on the player&#8217;s arms in first-person view, via mixin into <code>AvatarRenderer.renderRightHand/renderLeftHand</code>.</li>
</ul>

<h3>Fixed</h3>
<ul>
<li><strong>Armor not following animations</strong>: The armor model now receives the player&#8217;s render state via <code>setupAnim()</code>, matching the player&#8217;s pose.</li>
</ul>
