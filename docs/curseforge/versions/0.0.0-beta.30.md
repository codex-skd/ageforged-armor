<h2>v0.0.0-beta.30 — Fix render order: helmet now renders on top of player skin</h2>

<h3>Fix</h3>
<ul>
<li><strong>Helmet rendering behind player skin</strong>: increased <code>submitModel</code> order from <code>slot.ordinal() * 2</code> (0 for HEAD) to <code>1000 + slot.ordinal() * 2</code>. The player skin was rendering at a higher order than the armor, causing the head, top, and back of the helmet to be covered by the skin when looking up or down. Vanilla armor avoids this via a separate rendering pipeline with higher base order.</li>
</ul>

<h3>Infrastructure</h3>
<ul>
<li><strong>CurseForge upload filename fixed</strong>: the inline Python script used <code>b'...{version}...'</code> instead of <code>f'...{version}...'.encode()</code>, causing <code>{version}</code> to appear literally in the uploaded JAR name on CurseForge. Replaced with the shared PowerShell script at <code>codex-docs/scripts/curseforge-upload.ps1</code> which reads variables automatically from <code>gradle.properties</code> and <code>docs/curseforge/project_vars.md</code>.</li>
<li><strong>WORKFLOW updated to v1.2.1</strong>: role separation for <code>*/main</code> branch creation, shared upload script, branch table cleanup.</li>
<li><strong>Remote main branch created</strong>: <code>minecraft/26.1.2/neoforge-26.1.2.78/main</code> for GitHub mirror via CI/CD.</li>
</ul>
