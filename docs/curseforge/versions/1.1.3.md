<h2>v1.1.3 - Config files moved into config/ageforged_armor/</h2>

<h3>Change</h3>
<ul>
<li><strong>All generated config files now live in a dedicated folder</strong>: <code>config/ageforged_armor/</code>, instead of cluttering the root of <code>config/</code>. The main config is now <code>config/ageforged_armor/ageforged_armor.json</code> and the Patreon cache is <code>config/ageforged_armor/ageforged_armor_patrons_cache.json</code>.</li>
<li><strong>Automatic migration</strong>: on first launch, existing configs from the old locations (<code>config/ageforged_armor.json</code> and <code>config/config/ageforged_armor.json</code>) are copied into the new folder and the old files are cleaned up. Your settings are preserved.</li>
</ul>
