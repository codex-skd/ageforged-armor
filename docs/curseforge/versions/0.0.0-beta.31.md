<h2>v0.0.0-beta.31 — Fix helmet position offset causing skin to show through</h2>

<h3>Fix</h3>
<ul>
<li><strong>Helmet positioned 1 unit too low</strong>: all armor models called <code>templateLayerDefinition(1.0F)</code>, which offset every body part (head, body, arms, legs) by 1 block downward relative to the player model. This caused the player&#8217;s skin to be visible above and around the armor, especially noticeable on helmets when looking up or down — the skin would render in front of the armor. Changed to <code>templateLayerDefinition(0.0F)</code> so armor parts match the player model&#8217;s exact position, matching vanilla armor behavior.</li>
</ul>
