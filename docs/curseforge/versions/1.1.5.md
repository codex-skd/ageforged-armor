<h2>v1.1.5 - Fix invisible armor on non-player wearers (Armor Stand, tooltip previews)</h2>

<h3>Fix</h3>
<ul>
<li><strong>Custom armor rendered as nothing when worn by anything other than a real player</strong>: <code>MixinHumanoidArmorLayer</code> always blanked out the vanilla armor piece and handed rendering off to our own model, but that model (<code>ArmorModel</code>, which extends <code>PlayerModel</code> for BetterCombat/PlayerAnimationLib compatibility) only accepts an <code>AvatarRenderState</code>. Any other wearer — an Armor Stand, or the fake entity that tooltip-enhancer mods like Legendary Tooltips use to render a 3D item preview — hit that type check, bailed out, and drew nothing: an empty box in the tooltip, or an invisible piece on a real Armor Stand.</li>
<li><strong>Fix</strong>: when the wearer isn't a real player, a throwaway <code>AvatarRenderState</code> is now built from the same pose data (animation position, rotation, arm poses, etc.) so the custom model renders correctly there too. No behavior change for real players.</li>
</ul>
