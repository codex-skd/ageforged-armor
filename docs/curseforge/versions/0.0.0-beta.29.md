<h2>v0.0.0-beta.29 — Fix helmet rendering: front face disappearing when looking up</h2>

<h3>Fix</h3>
<ul>
<li><strong>Helmet front face disappearing</strong>: removed <code>copyPoseFromPlayer()</code> which was copying head rotations from the PlayerModel onto the armor model after <code>setupAnim(renderState)</code>. The PlayerModel pose could be stale or incomplete at that point in the render pipeline, causing the helmet to rotate out of sync with the player&#8217;s head. Now <code>setupAnim(renderState)</code> is the sole source of pose data, reading head pitch/yaw directly from the render state — matching vanilla armor behaviour exactly.</li>
<li><strong>Slim (Alex) model support fixed</strong>: <code>getArmorModel()</code> now uses the entity-based lookup (<code>Minecraft.getInstance().player</code>) instead of the state-based path, allowing <code>MixedArmorModelProvider</code> to correctly select the slim model variant when applicable.</li>
</ul>
