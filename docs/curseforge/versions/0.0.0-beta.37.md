<h2>v0.0.0-beta.37 — Fix FP arm: reset x/y/z to default + capture rotation from AvatarRenderer at TAIL</h2>

<h3>Fix</h3>
<ul>
<li><strong>Sneak animation leaking into first-person armor</strong>: <code>setupAnim</code> modifies x/y/z position and rotation of arm parts for sneaking/third-person animation. The armor arm inherited these transforms even in first person, causing it to shift when sneaking while the vanilla hand stayed fixed. Now resets x/y/z to the correct default shoulder position (&#177;5, 2/2.5, 0) based on slim/non-slim model.</li>
<li><strong>Exact first-person rotation</strong>: reads the arm rotation from the AvatarRenderer&#8217;s model at TAIL, after the render method has set it to the correct first-person pose — no more hardcoded approximations.</li>
</ul>
