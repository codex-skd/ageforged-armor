<h2>v0.0.0-beta.34 — Fix first-person arm armor pose — use fixed rotation matching actual first-person arm position</h2>

<h3>Fix</h3>
<ul>
<li><strong>Arm armor misaligned in first person</strong>: copying arm rotation from the AvatarRenderer model was unreliable because the model stores the third-person animation pose, not the first-person render pose. First-person arm position is determined by a fixed rotation applied during rendering, plus PoseStack transforms. Now uses a fixed base rotation matching the actual first-person arm angle (-1.2 xRot, slight zRot), with automatic sneak adjustment (-0.35 xRot when crouching) — matching the vanilla first-person arm behavior.</li>
</ul>
