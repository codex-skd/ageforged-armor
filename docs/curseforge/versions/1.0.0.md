<h2>v1.0.0 — First Stable Release</h2>

<p>After extensive beta testing and numerous fixes, Ageforged Armor reaches its first stable release. This version includes all fixes from beta.27 through beta.37.</p>

<h3>Fixes (from beta.27–beta.37)</h3>
<ul>
<li><strong>Helmet position offset</strong>: fixed <code>templateLayerDefinition</code> scale from 1.0F to 0.0F — armor parts now match the player model&#8217;s exact position.</li>
<li><strong>Helmet rendering behind skin</strong>: removed <code>copyPoseFromPlayer</code> which was causing the helmet face to disappear when looking up/down.</li>
<li><strong>First-person arm armor</strong>: now uses fixed rotation matching the actual first-person arm pose, with sneak adjustment. Position reset to default shoulder coordinates.</li>
<li><strong>Render order</strong>: increased <code>submitModel</code> order from 0 to 1000 to ensure armor renders on top of the player skin.</li>
<li><strong>CurseForge upload filename</strong>: fixed <code>{version}</code> literal in upload script.</li>
</ul>
