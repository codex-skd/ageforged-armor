## v0.0.0-beta.20

### Fixed
- **Bright white armor rendering**: Changed from `RenderTypes.entityCutout` to `RenderTypes.armorCutoutNoCull`, matching the vanilla `EquipmentLayerRenderer` pipeline. Fixes missing lighting, z-fighting with the player skin, and incorrect face culling on armor models.
- **Skin showing through helmet**: The armor pipeline now uses `VIEW_OFFSET_Z_LAYERING` which prevents z-fighting between the armor model and the player's skin underneath.
