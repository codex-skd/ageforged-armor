## v0.0.0-beta.20 - 🎨 Fix renderizado de armadura

### 🔧 Fixed
- **✨ Armadura blanca brillante**: Cambiado de `RenderTypes.entityCutout` a `RenderTypes.armorCutoutNoCull` — el pipeline correcto para armadura vanilla. Soluciona iluminación faltante, z-fighting con la skin del jugador y culling incorrecto de caras.
- **👕 Skin visible a través del casco**: El pipeline `armorCutoutNoCull` usa `VIEW_OFFSET_Z_LAYERING` que evita el z-fighting entre la armadura y la skin.
