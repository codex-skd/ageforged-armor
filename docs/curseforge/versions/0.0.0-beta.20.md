<h2>v0.0.0-beta.20 — Fix armor render type: use armorCutoutNoCull</h2>

<h3>Fix</h3>
<ul>
<li><strong>Bright white armor</strong>: Changed from <code>RenderTypes.entityCutout</code> to <code>RenderTypes.armorCutoutNoCull</code>, matching the vanilla <code>EquipmentLayerRenderer</code> pipeline. Fixes missing lighting, z-fighting with the player skin, and incorrect face culling.</li>
<li><strong>Skin showing through helmet</strong>: The armor pipeline now uses <code>VIEW_OFFSET_Z_LAYERING</code> which prevents z-fighting between the armor model and the player&#8217;s skin underneath.</li>
</ul>
