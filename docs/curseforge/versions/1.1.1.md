<h2>v1.1.1 - BetterCombat / PlayerAnimationLib Compatibility (real fix)</h2>

<h3>Fix</h3>
<ul>
<li><strong>1.1.0's fix was insufficient</strong>: manually copying per-bone pose did not fix the armor floating disconnected from the body during BetterCombat's dash attack. Root cause: vanilla armor uses <code>PlayerModel</code> instances (not a generic <code>HumanoidModel</code>) specifically so animation mods like PlayerAnimationLib, which mixin into <code>PlayerModel.setupAnim()</code>, sync it automatically. Ageforged Armor's model extended <code>HumanoidModel</code> directly, so that mixin never applied to it.</li>
<li><strong>Real fix</strong>: the armor model now extends <code>PlayerModel</code>, exactly like vanilla armor, so PlayerAnimationLib's animation syncing applies automatically. No behavior change when no animation mod is installed.</li>
</ul>
