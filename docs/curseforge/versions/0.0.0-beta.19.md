## v0.0.0-beta.19

### Fixed
- Crash when equipping any armor piece: `Can't find part hat` — all head armor models replaced the `head` part with `addOrReplaceChild("head", ...)`, losing the `hat` child that MC 26.1's `HumanoidModel` requires in its constructor. Changed to `root.getChild("head")` to preserve the existing `hat` part.
- `ArmorModel.templateLayerDefinition()` was adding `hat` as a root-level sibling of `head` instead of as a child of `head`, which also caused the crash.
