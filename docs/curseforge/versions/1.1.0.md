<h2>v1.1.0 - BetterCombat / PlayerAnimationLib Compatibility</h2>

<h3>Fix</h3>
<ul>
<li><strong>Armor desync while attacking with BetterCombat / PlayerAnimationLib</strong>: PlayerAnimationLib applies its attack animations (torso, arms, legs) directly on the player's model, but Ageforged Armor's armor model is a separate instance that only replayed the vanilla base animation, so it never followed those poses. The armor now mirrors the player's live pose (torso, arms, legs, head) each frame, so it stays aligned during combat animations. No change in behavior when no animation mod is installed.</li>
</ul>
