**Ageforged Armor** adds 11 unique armor sets to Minecraft, each with custom 3D models and hand-crafted textures. Every set comes with its own stats, set bonuses, and can be found as loot in vanilla structures.

---

## Features

- **Custom 3D Models** — Every armor piece has a unique 3D model, not just retextured vanilla armor
- **Set Bonuses** — Wear a full set to unlock special bonuses (hover over any piece to see details)
- **Configurable Stats** — Durability, defense, toughness, and enchantability are all configurable via YACL
- **Loot Generation** — Armor pieces can be found in vanilla structure chests (configurable per set and per structure)
- **Patron Skins** — O-Yoroi, Raijin, Pharaoh, and Centurion sets have alternate skin variants
