<h2>v0.0.0-beta.35 — Fix first-person arm armor position reset + rotation</h2>

<h3>Fix</h3>
<ul>
<li><strong>First-person arm armor misaligned</strong>: <code>setupAnim</code> modifies x/y/z position offsets on body parts during animation. The armor arm inherited these offsets, pushing it out of position in first person. Now resets x/y/z to 0 before applying the fixed first-person rotation. Arm rotation values: <code>xRot = -0.1F</code> (arm hanging naturally), <code>zRot = ±0.1F</code> (slight outward angle), with <code>-0.4F</code> sneak adjustment to follow the player when crouching.</li>
</ul>
