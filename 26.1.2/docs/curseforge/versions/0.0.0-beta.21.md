<h2>v0.0.0-beta.21 — Fix armor rendering: use correct submitModel signature</h2>

<h3>Fix</h3>
<ul>
<li><strong>Armor rendering now matches vanilla</strong>: Changed <code>submitModel</code> call to use the full 10-parameter signature via <code>collector.order()</code>, exactly as <code>EquipmentLayerRenderer</code> does. The previous 8-parameter call used a default overload that forwarded with wrong defaults.</li>
<li><strong>Bright white armor / missing texture</strong>: The corrected pipeline now properly samples the armor texture.</li>
<li><strong>Skin showing through helmet</strong>: Proper render ordering via <code>.order()</code> ensures correct depth testing between armor and player skin.</li>
</ul>
