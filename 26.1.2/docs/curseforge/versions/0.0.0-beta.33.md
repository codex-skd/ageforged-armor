<h2>v0.0.0-beta.33 — Fix arm armor flicker when opening inventory</h2>

<h3>Fix</h3>
<ul>
<li><strong>Armor arm snapped to wrong pose on inventory open</strong>: reading the arm rotation from <code>AvatarRenderer.getModel()</code> at TAIL could capture a stale pose if the model had been modified between the hand render and the injection point (e.g., when opening the inventory GUI). Now the rotation is captured at HEAD (before the hand renders), cached, and reused at TAIL for the armor render — eliminating the one-frame flicker where the armor shifted down then snapped back.</li>
</ul>
