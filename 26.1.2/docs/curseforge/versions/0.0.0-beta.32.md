<h2>v0.0.0-beta.32 — Fix first-person arm armor not following player pose</h2>

<h3>Fix</h3>
<ul>
<li><strong>Arm armor misaligned when sneaking</strong>: the first-person arm armor (<code>MixinAvatarRenderer</code>) was using hardcoded rotation values (<code>armPart.xRot = -0.1F</code>) instead of the player&#8217;s actual arm rotation. When sneaking or performing any action that changes arm pose, the armor stayed in a fixed position while the hand moved independently. Now reads the arm rotation directly from the AvatarRenderer&#8217;s model, so the armor arm follows the player&#8217;s real arm pose in all situations.</li>
</ul>
